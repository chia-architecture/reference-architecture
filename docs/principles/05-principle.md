# Reuse before buy before build

## Statement

We reuse existing solutions first, buy standard solutions second, and build custom solutions only as a last resort.

## Rationale

Custom development is expensive to build and maintain, which weighs heavily on small states. Shared and standard components benefit from scale and from the knowledge of a wider community.

## Implications

- Suitable digital public goods and open-source components are considered first.
- Standard software is not customised, unless the change is contributed back to the standard.
- Countries accept some local compromise to make shared solutions possible.
